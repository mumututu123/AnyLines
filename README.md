# AnyLine 在线事务管理

AnyLine 是一个基于 Flask + SQLite 的轻量级事务管理网站，用“主线 / 支线 / 事务节点”的方式管理事项推进、分叉、反合和闭环状态。项目内置单页前端，不依赖构建工具，启动 Flask 服务后即可在浏览器中使用。

## 功能特性

- 画布视图：以时间轴方式展示主线、支线、反合点和事务节点。
- 自定义里程碑：主线和支线均可添加里程碑节点，配置日期、目标描述，并从当前空间已有事务中多选验收条件；画布实时显示验收进度与完成状态。
- 项目空间：支持创建和切换多个相互隔离的项目空间，线、事务、配置、导出及回收站数据均按空间隔离。
- 账号权限：空间角色分为管理员和普通用户；管理员可创建空间并维护成员，所有成员均可读写所在空间的业务对象。
- 表格视图：新增事务时可快速搜索并选择所属主线或支线，并可按行编辑、自动保存。
- Excel 导入：使用一个模板批量创建主线、支线和事务，跨工作表校验通过后一次写入。
- Excel 导出：一个工作簿同时导出线和事务；导出选中事务时自动包含所属线及祖先线，文件可直接回导。
- 工作台筛选：支持关键词、线、责任人、状态、优先级、到期情况筛选，并可按日期、优先级、更新时间排序。
- 项目看板：统计主线、支线、事务及责任人状态分布，突出无主、风险和超期事务，并支持下钻列表后直接编辑。
- 我的情况：顶部统一入口汇总个人未闭环待办与未读协作通知，详情弹窗可在待办统计和通知列表间切换。
- 协作闭环：事务支持关注、评论和 `@成员`，创建、字段更新及依赖调整会进入动态时间线；“我的情况”集中接收指派、提及、评论、状态变化、依赖解除、临期和超期提醒。
- 概览指标：快速查看未闭环、风险、超期、即将到期、停留过久的事务。
- 主线与支线管理：支持名称、描述、自定义颜色、新建主线、从选中线创建支线、重命名、递归删除。
- 支线反合：支线可设置反合日期并回到父线。
- 事务管理：支持事务名、事务内容、闭环目标、下一步动作、风险原因、优先级、责任人、进展状态、起止日期。
- 事务编辑：事务名、事务内容、责任人、进展状态和起止日期必填，其余信息默认收纳在“更多描述”中；编辑已有事务时内容框会根据正文自动增高；事务内容支持直接粘贴并预览图片，以及拖拽上传、在线下载通用附件；新建弹窗因点击遮罩关闭时，会按项目空间和所属线暂存已填写内容。
- 事务依赖：支持关键字搜索、多对多前置依赖、画布拖拽连线和表格配置；前置事务未闭环时阻止依赖事务闭环。
- 依赖聚焦：在画布选中事务后自动高亮完整前置链和影响链，列出当前阻塞与直接受影响事务，并淡化无关节点。
- 语义缩放：缩小时按线路展示事务、风险和超期概览，标准倍率展示名称与状态，放大后展示责任人与日期；事务依赖线仅在选中有依赖关系的事务后显示。
- 画布图例：节点填充色统一表示进展状态，风险、超期、即将到期和停留过久在节点中央择优显示，边框仅表示当前事务及依赖方向。
- 状态枚举：默认包含 `未启动`、`进行中`、`有风险`、`等待中`、`已暂停`、`已闭环`、`已取消`，并支持在页面中配置。
- 状态停留时长：事务状态变化时自动重置计时。
- 风险与到期提醒：自动标记超期、7 天内到期、风险状态和状态停留过久的事务。
- 同日多事务聚焦：同一条线同一天存在多个事务时，标准信息密度下会聚合显示；点击重叠节点顶层可临时打开不改变画布倍率的焦点透镜，进入“详细”密度后则自动水平排开。
- 标签显示控制：可切换事务名、状态、停留时长、责任人标签。
- 责任人选择：事务责任人下拉选项直接来自当前项目空间的成员清单。
- 批量操作：表格视图支持多选后批量修改状态、责任人、优先级或批量删除。
- 回收站：删除线、事务或里程碑后进入回收站，支持按删除批次恢复或永久清空。
- 通用撤销与恢复：画布视图支持使用 `Ctrl+Z` 撤销最近一次线、事务或里程碑编辑，并使用 `Ctrl+R` 恢复该次撤销。
- 本地偏好记忆：画布 / 表格视图、缩放比例、标签显示配置会保存在浏览器 `localStorage`。

## 环境要求

- Python 3.8+
- Flask

## 快速开始

1. 创建并激活虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. 安装依赖：

```powershell
pip install -r requirements.txt
```

3. 启动服务：

```powershell
python app.py
```

4. 打开浏览器访问：

```text
http://localhost/
```

首次启动会创建初始管理员账号：

```text
账号：admin
密码：admin123
```

登录后请通过右上角“修改密码”立即更换初始密码。首次初始化前可通过
`ANYLINE_ADMIN_USERNAME` 和 `ANYLINE_ADMIN_PASSWORD` 环境变量修改初始凭据。

默认服务监听 `0.0.0.0:80`。如果当前用户没有绑定 80 端口的权限，或者端口已被占用，可以将 [app.py](./app.py) 末尾的端口改为其他端口，例如：

```python
app.run(host="0.0.0.0", port=5000, debug=False)
```

然后访问：

```text
http://localhost:5000/
```

## 运行测试

测试使用临时 SQLite 数据库，不会读写项目中的 `anyline.db`。测试会启动一个仅监听本机随机端口的 HTTP 服务，覆盖线、事务、批量操作、撤销、回收站、配置、输入校验和旧数据库迁移。

```powershell
python -m unittest discover -s tests -v
node --check static\app.js
```

也可以通过环境变量为服务指定其他数据库文件：

```powershell
$env:ANYLINE_DB_PATH = "D:\data\anyline.db"
python app.py
```

生产或共享环境还应设置稳定且随机的会话密钥：

```powershell
$env:ANYLINE_SECRET_KEY = "请替换为足够长的随机字符串"
python app.py
```

## 数据说明

项目使用根目录下的 `anyline.db` 作为 SQLite 数据库。启动时会自动调用 `init_db()` 创建缺失的数据表。

主要数据表：

- `users`：账号、显示姓名及密码哈希。
- `workspaces`：项目空间。
- `workspace_members`：账号与空间的成员关系及空间角色。
- `workspace_meta`：按空间保存状态列表和删除批次序号。
- `undo_snapshots`：按空间保存最近一次线或事务编辑前的撤销快照。
- `redo_snapshots`：按空间保存最近一次撤销前的恢复快照。
- `lines`：带项目空间归属的主线、支线及软删除信息。
- `tasks`：带项目空间归属的事务内容、状态和时间信息。
- `milestones`：主线或支线上的里程碑名称、日期、目标描述及软删除信息。
- `milestone_tasks`：里程碑与验收事务之间的多对多关联。
- `task_dependencies`：事务与其前置事务之间的多对多依赖关系。
- `task_followers`：事务关注人与订阅关系。
- `task_comments`：事务评论及作者信息。
- `task_activities`：事务创建、字段变化和依赖调整记录。
- `notifications`：按账号和空间隔离的站内通知及已读状态。

已有数据库升级时，原有业务数据和配置会自动迁入“默认项目”，不会清空。

如需清空全部数据，可以先停止服务，再备份或删除 `anyline.db`，之后重新启动应用生成新数据库。

## 使用说明

### 画布视图

- 点击 `+ 主线` 创建第一条主线。
- 选中一条线后，可以创建支线、添加事务或里程碑；双击线条可以编辑线。
- 点击里程碑五角星节点可编辑名称、日期、目标描述和验收事务；在验收条件中双击事务可进入事务编辑，关闭后返回并保留里程碑表单。星形按各状态的事务数量占比显示竖向色带，颜色从左到右按状态成熟度由低到高排列；未配置验收事务时显示黄色空心星。
- 选中一条线后按 `Delete` 可递归删除该线、子支线及相关事务。
- 按 `Ctrl+Z` 可撤销最近一次线、事务或里程碑的新增、修改、反合或删除操作；按 `Ctrl+R` 可恢复该次撤销。
- 按 `H` 可聚焦今天；选中主线或支线后，按 `B` 可创建支线，按 `A` 或 `N` 可创建事务。
- 画布左侧会集中显示当前生效的全部画布快捷键。
- 双击事务节点可以编辑事务。
- 单击选中事务节点后，从该节点按住左键拖向前置事务节点，可建立单向依赖关系。
- 依赖关系以指向前置事务的虚线箭头显示。
- 支线选中后可点击 `反合` 设置反合日期。
- 同一条线同一天有多个事务时，标准信息密度下会显示重叠的聚合节点。点击顶层节点会打开局部焦点透镜，在不改变画布倍率和位置的情况下查看、选择或编辑各事务。点击关闭、画布空白处或按 `Esc` 可退出聚焦；进入“详细”密度后会自动水平排开。
- `Ctrl + 鼠标滚轮` 缩放画布。
- 左键长按拖动可平移画布。
- 点击 `聚焦今天` 可滚动到今日时间线。
- 点击 `适应画布` 可恢复默认缩放并回到左上角。
- 选中有子支线的线后，可折叠或展开其子支线。
- 使用顶部筛选区后，画布只显示匹配筛选条件的事务节点。

### 表格视图

- 点击 `表格视图` 切换到事务列表。
- 点击 `导入数据` 下载统一模板；“线导入”和“事务导入”可只填写一张，也可同时填写后一次上传。
- 线使用文件内唯一的“线标识”和“父线标识”建立层级；事务可通过该线标识、已有线 ID 或完整路径匹配所属线。
- 任一工作表存在错误时，主线、支线和事务均不会写入，错误弹窗会标明工作表和行号。
- 点击 `导出全部数据` 会在一个工作簿中导出全部线和事务；`导出选中事务` 会自动带上事务所属线及其祖先线，导出文件可直接回导。
- 单元格可直接编辑，修改后会自动保存。
- 可在表格中切换事务所属线、责任人、进展状态和日期。
- 可通过“依赖事务”列配置一个事务的多个前置事务。
- 勾选多行后，可批量修改状态、责任人、优先级或批量删除。
- 点击 `定位` 可切换到画布并定位对应事务节点。
- 点击行内 `删除` 可删除事务。

### 撤销编辑

画布视图中按 `Ctrl+Z` 可以撤销最近一次线或事务编辑，按 `Ctrl+R` 可以恢复该次撤销。撤销与恢复均为单步操作；撤销后执行新的编辑会清除恢复点，并以新编辑前的状态替换撤销点。

删除的线或事务也可以进入 `回收站`，按删除批次恢复历史删除。

点击 `清空回收站` 会永久删除已删除数据，此操作不可撤销。

### 责任人选择

事务的责任人选项直接读取当前项目空间的成员清单。空间管理员可通过 `成员管理` 添加、修改或移除成员；变更后，事务编辑、表格批量修改和 Excel 导入模板中的责任人选项会同步更新。

### 协作与通知

- 编辑已有事务时，展开“协作与动态”可以关注事务、发表评论并查看变更时间线。
- 评论输入框中键入 `@` 后，可按姓名或账号前缀联想当前空间成员；被提及人会收到提及通知，评论作者会自动关注该事务。
- 事务创建者默认关注自己创建的事务；责任人无需关注也会收到指派、状态变化和依赖解除等重要通知。
- 顶部铃铛显示当前项目空间的未读数。单击通知可标记已读并打开关联事务，也可一键全部标为已读。
- 系统在读取通知或项目状态时生成去重的临期与超期提醒，不依赖额外的定时任务。

### 状态设置

点击 `状态设置`，可逐项维护进展状态名称及对应颜色。已有事务使用过的历史状态会继续保留，避免配置变更后旧数据无法编辑；配置颜色会同步应用到画布节点、持续时间条和状态选择控件。

## REST API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/auth/login` | 登录 |
| `POST` | `/api/auth/logout` | 退出登录 |
| `GET` | `/api/auth/session` | 获取当前账号、空间及角色 |
| `PUT` | `/api/auth/password` | 修改当前账号密码 |
| `POST` | `/api/workspaces` | 管理员创建并切换到新空间 |
| `POST` | `/api/workspaces/<id>/select` | 切换项目空间 |
| `GET/POST` | `/api/workspaces/<id>/members` | 管理员查看或添加空间成员 |
| `PATCH/DELETE` | `/api/workspaces/<id>/members/<user_id>` | 管理员维护角色、账号或移除成员 |
| `GET` | `/api/state` | 获取线、事务、状态枚举、责任人、撤销/恢复状态和当前日期 |
| `GET` | `/api/notifications` | 获取当前账号在当前空间的最近通知和未读数 |
| `POST` | `/api/notifications/read-all` | 将当前空间的全部通知标为已读 |
| `POST` | `/api/notifications/<id>/read` | 将指定通知标为已读 |
| `GET` | `/api/statuses` | 获取进展状态及颜色配置 |
| `PUT` | `/api/statuses` | 更新进展状态及颜色配置 |
| `POST` | `/api/lines` | 创建主线或支线 |
| `PATCH` | `/api/lines/<id>` | 更新线名、起始日期或反合日期 |
| `DELETE` | `/api/lines/<id>` | 递归删除线、子支线及相关事务 |
| `POST` | `/api/tasks` | 创建事务 |
| `PATCH` | `/api/tasks/<id>` | 更新事务 |
| `DELETE` | `/api/tasks/<id>` | 删除事务 |
| `GET` | `/api/tasks/<id>/collaboration` | 获取事务关注人、成员和协作时间线 |
| `POST/DELETE` | `/api/tasks/<id>/follow` | 关注或取消关注事务 |
| `POST` | `/api/tasks/<id>/comments` | 发表评论并触发协作通知 |
| `GET` | `/api/data/import-template` | 下载主线、支线和事务统一 Excel 导入模板 |
| `POST` | `/api/data/import` | 原子校验并批量导入线和事务 |
| `POST` | `/api/data/export` | 导出全部数据或选中事务及关联线 |
| `PATCH` | `/api/tasks/bulk` | 批量更新事务状态、责任人、优先级或所属线 |
| `DELETE` | `/api/tasks/bulk` | 批量删除事务 |
| `POST` | `/api/undo` | 撤销最近一次线或事务编辑 |
| `POST` | `/api/redo` | 恢复最近一次撤销的线或事务编辑 |
| `GET` | `/api/trash` | 查看回收站 |
| `POST` | `/api/trash/restore` | 按删除批次恢复回收站数据 |
| `POST` | `/api/trash/purge` | 永久清空回收站 |

## 部署注意事项

当前实现适合本地或内网轻量使用。公开部署时必须设置
`ANYLINE_SECRET_KEY`、更换初始管理员密码，并在 Flask 前配置 HTTPS 反向代理。

- SQLite 更适合单机、小团队、低并发场景。
- `python app.py` 使用的是 Flask 内置服务，不建议直接作为公网生产服务。
- 对外暴露前建议增加反向代理、访问控制、备份机制和更完整的日志策略。
