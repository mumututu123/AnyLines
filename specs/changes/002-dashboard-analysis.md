# 辅助分析：项目地图

日期：2026-09-08。关联需求：AL-DASH-002。范围：项目看板的“辅助分析”。

## 行为与验收

- 时间回放：从启用后的每日场景快照中选择日期、逐步播放，展示当时的线、事务、依赖和里程碑；旧汇总数据不得伪装成场景历史。一天保留最后一次访问状态时的场景，提供最近 90 个记录日。
- 延期推演：选择未完成事务和延期天数后实时刷新，不设置额外提交按钮。所选事务保持开始日期、只延长结束日期；下游事务按“前置结束后后续才能开始、原工期保持”的假设传递新增延误，多前置取最大约束，已有排期冲突不算新增延误，已完成事务不参与传播。“预计日期变化”使用甘特泳道对照原计划与推演后日期，并展示依赖链涉及的事务、里程碑、所属支线及祖先主线。图中不绘制对象间依赖线；原计划使用灰色细条、推演后使用蓝色粗条，指定事务新增时间使用橙色，并在泳道末尾标注影响天数。双击事务或里程碑泳道打开对应编辑详情，关闭后恢复延期影响页的选择、滚动位置和键盘焦点。推演不提交业务修改。
- 计划影子：用户主动保存当前全项目基线，显示日期轨迹与增删变化；更新基线为明确按钮操作。
- 汇报路径：可添加事务、线或里程碑，编辑说明、调整顺序、逐步讲解；画面聚焦该步骤关联对象。
- 最近变化：比较用户上次明确确认的快照与当前状态，列出事务、线、依赖和里程碑的新增、移除及字段变化，支持定位当前事务；打开工具不得自动清除尚未确认的变化。
- 里程碑展开：按已闭环、已取消、推进中、受阻展示验收事务，取消不计入验收完成。

全部分析采用当前完整项目空间，页面明确说明不跟随顶部筛选或汇报周期。历史缺失、项目为空、无依赖、无里程碑时有可操作或解释性的空状态。兼容暗色、窄屏、键盘；切换项目、退出或折叠分析时停止播放，异步历史响应不得串入其他项目。

## 数据与权限

`dashboard_snapshots` 增加可空的 `scene` 与 `captured_at` 列，通过现有启动迁移自动补齐。场景仅保留地图分析字段，不保存正文、附件或账号敏感信息。`GET /api/dashboard/history` 返回日期目录；`GET /api/dashboard/history/<date>` 返回当前空间指定日期的场景。沿用登录和空间成员权限，归档空间允许浏览；不开放操作审计接口。

基线、变化确认点和汇报路径保存于当前浏览器，按账号 ID 与空间 ID 隔离；存储失败明确反馈。无新业务写接口，无撤销或审计口径变更。场景采集沿用 `/api/state` 的每日快照机制。删除项目时随快照表记录清理。旧版客户端继续使用原汇总字段。

当本地没有变化确认点或基线时，用户可以明确选择一个历史记录作为比较起点。选择操作会把该场景保存到当前浏览器；仅打开页面不得自动移动变化确认点。
