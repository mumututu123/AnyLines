# AnyLine 产品与需求规范

文档编号：AL-PRD-001 · 版本：1.0 · 状态：基线评审稿 · 日期：2026-09-07

关联：[规范基线](README.md) · [验收矩阵](acceptance.md)

## 1. 产品定位

AnyLine 服务于企业部门内围绕同一目标协同推进事项的小团队。系统以项目空间组织工作，以主线、支线表达工作展开关系，以事务记录具体承诺、责任、日期和状态，以依赖关系和里程碑表达交付约束。

产品应支持成员更新工作、识别阻塞、交换上下文，也应支持管理员查看整体进展并追溯操作。画布、表格和看板是同一业务数据的不同呈现方式，不应形成相互独立的数据副本。

### 1.1 业务目标

| 目标 | 用户可感知的结果 | 评价方法 |
| --- | --- | --- |
| 工作可见 | 可以找到事项责任人、当前状态、计划日期与下一步动作 | 按真实事项完成查找和更新任务 |
| 协作可推进 | 可以定位前置事项、被阻塞事项及讨论记录 | 演示依赖建立、解除与通知 |
| 汇报可复用 | 日常记录可汇总为看板与周期进展报告 | 核对汇报条目与源事务 |
| 变更可追溯 | 管理员可查询用户对当前空间的成功编辑及前后快照 | 用创建、修改、删除链路验收 |

评价方法为试用与验收依据；本基线不宣称已测得效率提升比例。

### 1.2 范围边界

当前范围包括账号、项目空间、成员维护、线与事务、依赖、里程碑、图片附件、Excel 导入导出、协作通知、看板、回收站、单步撤销重做、主题与头像、审计查询。

当前不包含跨空间个人工作台、接单确认、正式审批流、独立验收人、工时成本管理、企业 IM 推送、SSO、离线编辑、实时协同冲突合并、多级撤销或独立防篡改存证。这些能力需另立变更规格。

## 2. 术语与语义

| 术语 | 定义 |
| --- | --- |
| 项目空间 | 业务数据、成员权限、配置和审计查询的隔离边界 |
| 主线 | 没有父线的工作线 |
| 支线 | 具有父线、在某日期从父线展开的工作线；允许嵌套 |
| 反合 | 为支线指定回到父线的日期；不等同于关闭线上全部事务 |
| 事务 | 有内容、责任人、状态和日期的最小跟踪对象 |
| 前置依赖 | 事务 B 依赖事务 A，表示 B 的闭环受到 A 状态约束 |
| 里程碑 | 某线上的阶段目标，通过关联事务展示验收进度 |
| 业务动态 | 面向协作的事务时间线；与管理员专用审计日志分开 |
| 对象快照 | 操作时对象的结构化状态，审计保存操作前、操作后两份 |

需要特别区分“已结束”和“已闭环”：待办、部分看板与里程碑展示把 `已闭环`、`已取消` 都视为已结束；依赖闭环校验要求前置事务的状态严格为 `已闭环`。本基线保留该行为，统一语义列入后续评审事项。

## 3. 角色与权限

角色属于“用户在某个空间的成员关系”。同一用户在一个空间是管理员，不代表在其他空间也拥有管理员权限。

| 能力 | 未登录 | 普通成员 | 当前空间管理员 |
| --- | --- | --- | --- |
| 打开登录页 | 允许 | 允许 | 允许 |
| 浏览所属空间、画布、表格、看板 | 不允许 | 允许 | 允许 |
| 编辑线、事务、依赖、里程碑 | 不允许 | 未归档时允许 | 未归档时允许 |
| 评论、关注、导入、批量编辑、修改状态配置 | 不允许 | 未归档时允许 | 未归档时允许 |
| 导出、查看本人通知、标记通知已读 | 不允许 | 允许 | 允许 |
| 撤销、重做、恢复及清空回收站 | 不允许 | 未归档时允许 | 未归档时允许 |
| 维护空间资料和成员 | 不允许 | 不允许 | 未归档时允许，账号维护另有归属限制 |
| 归档、恢复、永久删除空间 | 不允许 | 不允许 | 允许，须通过业务校验 |
| 查询当前空间审计及快照 | 不允许 | 不允许 | 允许，包含已归档空间 |
| 修改本人密码、头像和主题 | 不允许使用账号接口 | 允许 | 允许 |

拥有任一空间管理员角色的用户可创建新空间。成员账号姓名和密码由其维护管理员修改；其他空间管理员仅可调整该账号在本空间的角色。空间管理员不得移除自己，且空间须至少保留一名管理员。

## 4. 功能需求

### 4.1 身份、项目空间与配置

| 编号 | 规范要求 |
| --- | --- |
| AL-AUTH-001 | 系统必须通过账号密码建立会话；业务 API 必须校验有效账号与空间成员关系。未登录访问受保护接口返回 401。 |
| AL-AUTH-002 | 用户必须能够修改本人密码和头像；管理员维护成员账号时必须遵守账号维护归属与最后一名管理员约束。 |
| AL-WS-001 | 空间必须隔离线、事务、依赖、里程碑、配置、回收站、通知与审计；对象 ID 不得绕过空间校验。切换空间必须清理前一空间的选择与审计展示状态。 |
| AL-WS-002 | 管理员必须能够创建、修改、归档、恢复和删除空间。归档空间的业务编辑必须返回冲突；删除必须核对输入的空间名称，并保留至少一个操作者可访问的空间。 |
| AL-CFG-001 | 未归档空间成员必须能够配置状态名称和颜色；已有事务使用的历史状态必须继续可用。责任人候选必须来自当前空间成员。 |

账号长度为 2–40 字符且不含空白，密码长度为 6–128 字符。默认状态为未启动、进行中、有风险、等待中、已暂停、已闭环、已取消；优先级为低、中、高、紧急。状态为可配置枚举，系统没有通用的审批式状态流转矩阵。

### 4.2 工作线、事务与依赖

| 编号 | 规范要求 |
| --- | --- |
| AL-LINE-001 | 系统必须支持主线和嵌套支线的创建、修改和删除，记录名称、描述、颜色及起始日期；父线必须属于当前空间且未删除。 |
| AL-LINE-002 | 支线起始日期不得早于父线起始日期；线调整起始日期不得晚于现有子支线、线上事务或里程碑的相关日期。主线不得反合，支线反合日期不得早于其起始日期。 |
| AL-TASK-001 | 事务必须支持创建、更新和删除。名称、内容、责任人、状态和起止日期必须符合校验；系统还应保存闭环目标、下一步动作、风险原因和优先级。 |
| AL-TASK-002 | 表格必须支持行内保存、所属线选择和批量更新。批量更新仅允许所属线、责任人、状态和优先级；任一对象校验失败时不得部分提交。 |
| AL-DEP-001 | 前置依赖必须限定为当前空间有效事务，不得自依赖、重复或形成循环。闭环时必须校验全部前置事务已闭环；删除仍被外部有效对象引用的事务必须被阻止。 |

事务日期使用日历日期；结束日期不得早于起始日期，起始日期不得早于所属线起始日期。状态变化须重置 `status_since`；普通内容编辑不应被解释为状态变化。`updated_at` 是日期字段，不具备可靠的并发版本号语义。

依赖关系的画布箭头从依赖事务指向前置事务。依赖不自动推算任务工期，不自动排程，也不保证重新打开前置事务后自动回退下游状态。

### 4.3 里程碑、附件与数据交换

| 编号 | 规范要求 |
| --- | --- |
| AL-MILE-001 | 里程碑必须具有所属线、名称、目标描述、日期及可选验收事务集合；日期不得早于所属线起始日期，验收事务必须在当前空间内且未删除。 |
| AL-MILE-002 | 画布必须展示里程碑及验收事务的状态分布；编辑验收事务后可返回里程碑表单。仍被有效里程碑引用的事务不得单独删除。 |
| AL-FILE-001 | 事务必须支持粘贴图片、添加与下载附件；服务端必须校验格式、大小和归属，读取文件时必须检查当前空间及所属业务对象有效性。 |
| AL-IO-001 | 系统必须提供统一 Excel 模板与导入入口，支持文件内线层级和事务归属映射；任一工作表无效时，整个导入不得写入业务数据。 |
| AL-IO-002 | 系统必须能够导出全部数据或选中事务及其所属线和祖先线；导出文件支持业务字段回导，但不得被描述为完整数据库备份。 |

图片支持 PNG、JPEG、GIF、WebP，每事务最多 8 张、单张不超过 5 MiB、合计不超过 20 MiB。附件每事务最多 8 个、单个不超过 5 MiB、合计不超过 20 MiB，文件名上限 180 字符。统一导入文件不超过 5 MiB，线和事务各最多 2,000 行。

里程碑允许验收集合为空；空集合显示未配置状态，不得视为已经完成验收。当前没有独立的里程碑签署人或人工审批过程。

### 4.4 协作、个人待办与进展展示

| 编号 | 规范要求 |
| --- | --- |
| AL-COL-001 | 新建和编辑事务均须显示右侧协作栏；新建时可随事务发布首条动态，编辑时可关注事务、评论及提及当前空间成员。有关注者或动态时协作栏默认展开，无记录时收纳为右侧居中的竖向轨道入口，窄屏下移至表单下方。创建、字段与依赖变化进入业务动态，相关参与者接收对应站内通知。评论长度为 1–2,000 字符。 |
| AL-COL-002 | “我的情况”必须汇总当前空间的本人未结束待办及未读通知，允许切换统计和通知列表；通知支持单条及全部已读。 |
| AL-COL-003 | “协作通知”必须仅包含其他成员行为触发的指派、提及、评论、状态变化和依赖解除；临期与超期只在“我的待办”按实时事务状态展示，不进入协作通知或其未读数。前端在登录且页面可见时每 30 秒轮询协作通知。 |
| AL-VIEW-001 | 画布与表格必须使用同一份业务状态，提供搜索、责任人、状态、优先级、日期等筛选；画布支持缩放、折叠、依赖聚焦和同日节点聚合。 |
| AL-DASH-001 | 看板必须提供总体进展、成果、计划偏差、风险与阻塞，以及责任人负荷和趋势辅助分析；支持近 7 天、近 30 天、全周期、下钻、会议模式和打印。 |
| AL-DASH-002 | 辅助分析必须提供项目地图的变化对比、个人计划基线、只读延期推演、每日场景回放、可编排汇报路径与里程碑验收分组。范围、计算假设、历史起点与本地保存范围须明确，详见 [项目地图变更规格](changes/002-dashboard-analysis.md)。 |

临期为距结束日期 0–7 天，超期为结束日期早于今日，停留过久为未结束且当前状态持续至少 7 天。风险标记按 `有风险` 状态识别。今日取服务端业务日期，不是精确到时分的截止时间。

看板按当前状态与日期聚合；日快照在访问项目状态时生成/更新，同日覆盖，接口最多返回最近 90 条日快照。未访问日期不承诺有快照。成果使用当前闭环状态及 `status_since` 归入周期，不能视为不可变的历史交付账本。

### 4.5 恢复、界面偏好与审计

| 编号 | 规范要求 |
| --- | --- |
| AL-REC-001 | 线、事务和里程碑删除必须进入空间内回收站；级联删除共享批次，恢复必须检查父线、前置事务和验收条件的恢复顺序。 |
| AL-REC-002 | 系统必须提供空间级单步撤销/重做。新编辑覆盖撤销点并清除重做点；清空回收站清除相关业务数据及恢复点，但不得删除审计记录。 |
| AL-UX-001 | 头像菜单右上角必须在上传头像按钮左侧提供同风格太阳/月亮按钮；切换更新主题与可访问名称，并保存用户选择。无显式选择时跟随系统主题。 |
| AL-UX-002 | 表单错误必须可见；新建事务点击遮罩关闭时按空间和所属线暂存草稿。草稿是页面内存状态，刷新或退出后的持久恢复不在本版本承诺内。 |
| AL-AUD-001 | 审计入口必须位于头像菜单底部，仅当前空间管理员可见；服务端必须独立校验同等权限。 |
| AL-AUD-002 | 系统必须记录所有纳入审计范围且实际改变对象的成功编辑，包括账号、操作类型、操作对象、对象快照、时间与请求标识。 |
| AL-AUD-003 | 编辑结果与审计必须原子提交；审计写入失败必须回滚业务修改，失败请求不得生成成功编辑日志。 |
| AL-AUD-004 | 审计必须按对象保存操作前后快照；密码不得进入快照，文件保存元数据和摘要，不复制二进制内容。 |
| AL-AUD-005 | 审计必须支持账号、操作、对象、时间筛选及分页；详情读取必须继续限制在当前空间。 |
| AL-AUD-006 | 审计必须只追加，撤销、删除、回收站清理不能抹去已有记录；空间永久删除后保留数据库记录，但不通过其他空间查询。 |

审计的具体对象范围、操作代码和异常场景见 [审计专项](features/001-audit.md)。浏览器主题修改、登录、查询、导出和通知已读不属于编辑审计范围。

## 5. 非功能要求与部署约束

| 编号 | 要求 | 当前基线边界 |
| --- | --- | --- |
| AL-NFR-001 | 权限必须在服务端验证，输入必须校验，页面展示用户内容须避免作为 HTML 执行 | 不代表已完成渗透测试；公网使用前需独立安全评估 |
| AL-NFR-002 | 数据必须可持久保存；升级必须保留已有业务数据并初始化缺失结构；导入与审计写入须具备失败回滚能力 | 不包含自动备份、异地容灾或承诺的 RPO/RTO |
| AL-NFR-003 | 系统应能在部署方确认的数据规模下完成核心操作，报告容量及延迟测试结果 | 尚未建立并发数、P95 延迟或可用率 SLA，不填写未经测量的数值 |
| AL-NFR-004 | 核心界面应支持键盘操作、可见焦点和日夜主题，审计页支持窄屏查询 | 现有浏览器验证集中于 Chrome；完整兼容性及无障碍认证不在当前证据范围内 |

## 6. 待评审事项

| 编号 | 当前事实 | 需决定的问题 |
| --- | --- | --- |
| OPEN-01 | 责任人以显示姓名存储和匹配个人待办 | 是否迁移为稳定用户 ID，如何处理同名与改名 |
| OPEN-02 | 已取消参与“已结束”统计，但不满足依赖闭环校验 | 是否统一完成语义，并明确取消前置事项后的处理 |
| OPEN-03 | 普通成员可编辑所有空间业务对象，也可清空回收站 | 是否细化删除、恢复、配置和责任人调整权限 |
| OPEN-04 | 撤销点由空间共享且仅有一步 | 是否改为按操作者记录或加入冲突防护 |
| OPEN-05 | 修改未采用乐观锁或字段级冲突合并 | 多人编辑是否需要版本号与冲突提示 |
| OPEN-06 | 审计无自动保留期限，永久删除空间后无页面入口 | 数据保留周期、离线归档和后续检索政策是什么 |
| OPEN-07 | 性能及灾备指标未约定 | 目标数据规模、并发、备份周期及恢复指标是什么 |

待评审事项是后续决策输入，不在本次文档整理中隐含变更现有权限或业务行为。
